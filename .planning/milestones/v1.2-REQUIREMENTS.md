# Requirements Archive: v1.2 Revamp Other User Profile View

**Archived:** 2026-03-13
**Status:** All requirements complete

## v1.2 Requirements (Complete)

### Backend API

- [x] **API-01**: Authenticated user can fetch another user's public profile (username, display name, avatar, watched count, friends count, blends count) — Phase 7
- [x] **API-02**: Authenticated user can fetch another user's watched movies (paginated, with tmdb_id, title, poster, rating) — Phase 7
- [x] **API-03**: Authenticated user can fetch another user's friends list (id, username, display name, avatar) — Phase 7
- [x] **API-04**: All three public profile endpoints return 403 if the caller is not friends with the target user — Phase 7

### iOS Frontend

- [x] **IOS-01**: User sees stats row on friend profile (watched count, friends count, blends count) — Phase 9
- [x] **IOS-02**: User sees 3-column poster grid of friend's watched movies with star ratings — Phase 9
- [x] **IOS-03**: User can tap a watched movie poster to navigate to MovieDetailView — Phase 9
- [x] **IOS-04**: User can tap friends count to see friend's friends list — Phase 9
- [x] **IOS-05**: User can tap a friend-of-friend to open their profile (recursive navigation) — Phase 9
- [x] **IOS-06**: PosterTile and StatsRow extracted as shared components used by both ProfileView and FriendProfileView — Phase 8
- [x] **IOS-07**: Loading and empty states displayed while data loads or when friend has no watched movies — Phase 9

## v1.1 Requirements (Complete)

### Import Flow

- [x] **IMPT-01**: User can tap "Import from Letterboxd" from Profile to start the import flow — Phase 5
- [x] **IMPT-02**: User sees an in-app webview loading Letterboxd's data export page — Phase 5
- [x] **IMPT-03**: User can log into Letterboxd within the in-app webview — Phase 5
- [x] **IMPT-04**: When user taps "Export Your Data" on Letterboxd, the app intercepts the ZIP download without leaving the app — Phase 5
- [x] **IMPT-05**: After ZIP is captured, the app automatically uploads it to the backend import endpoint — Phase 6
- [x] **IMPT-06**: User sees a loading indicator while the import is processing — Phase 6
- [x] **IMPT-07**: User sees import results (imported/skipped/failed counts) when import completes — Phase 6
- [x] **IMPT-08**: User can tap Done to return to Profile after viewing results — Phase 6
- [x] **IMPT-09**: User sees an error message if the import fails, with ability to retry — Phase 6

### Backend

- [x] **BKND-01**: Taste profile is automatically rebuilt after a successful bulk import — Phase 4
