  <action>
    Create `blnd_backend/app/import_data/workflows.py` with the following:

    **Imports:** `csv`, `io`, `logging`, `zipfile` from stdlib; `dataclass` from dataclasses; `date` from datetime; `httpx`; `Session` from sqlalchemy.orm.

    **FilmRecord dataclass:**
    ```python
    @dataclass
    class FilmRecord:
        uri: str
        name: str
        year: int | None
        rating: float | None = None
        review: str | None = None
        watched_date: date | None = None
        in_watched: bool = False
        in_watchlist: bool = False
        watchlist_date: date | None = None
        liked: bool = False
    ```

    **`_parse_csvs(file_bytes: bytes) -> dict[str, FilmRecord]`** (private helper):
    - Open `zipfile.ZipFile(io.BytesIO(file_bytes))`
    - Define target files: `["watched.csv", "ratings.csv", "reviews.csv", "likes/films.csv", "watchlist.csv"]`
    - Get `zf.namelist()` to check which files exist
    - Initialize `merged: dict[str, FilmRecord] = {}` keyed by Letterboxd URI
    - Process each CSV in this order (per research recommendation): watched.csv, ratings.csv, reviews.csv, likes/films.csv, watchlist.csv
    - For each target file, skip if not in `zf.namelist()` (handles missing CSVs gracefully per Pitfall 3)
    - Open each file with `zf.open(name)` wrapped in `io.TextIOWrapper(raw, encoding='utf-8')`, read with `csv.DictReader`

    **Per-CSV parsing logic:**

    *watched.csv:* For each row, get `uri = row['Letterboxd URI']`. If URI not in merged, create `FilmRecord(uri=uri, name=row['Name'], year=int(row['Year']) if row.get('Year') else None)`. Set `record.in_watched = True`. Set `record.watched_date = date.fromisoformat(row['Date']) if row.get('Date') else None` (fallback watched_date from Date column per CONTEXT.md decision).

    *ratings.csv:* For each row, get or create FilmRecord by URI. Set `record.rating = float(row['Rating']) if row.get('Rating') else None` (CSVP-05: floats 0.5-5.0; CSVP-07: empty = None not 0).

    *reviews.csv:* For each row, get or create FilmRecord by URI. Set `record.review = row.get('Review') or None`. Set `record.rating = float(row['Rating']) if row.get('Rating') else None` (CSVP-07). Set `record.watched_date = date.fromisoformat(row['Watched Date']) if row.get('Watched Date') else record.watched_date` (CSVP-06: use Watched Date column, not Date; only overwrite if present — reviews.csv Watched Date takes priority over watched.csv Date per CONTEXT.md).

    *likes/films.csv:* For each row, get or create FilmRecord by URI. Set `record.liked = True`. Note: the zip path is `likes/films.csv` not `films.csv` (Pitfall 2).

    *watchlist.csv:* For each row, get or create FilmRecord by URI. Set `record.in_watchlist = True`. Set `record.watchlist_date = date.fromisoformat(row['Date']) if row.get('Date') else None`.

    **When getting or creating a FilmRecord:** If URI already in `merged`, use existing. Otherwise create `FilmRecord(uri=uri, name=row['Name'], year=int(row['Year']) if row.get('Year') else None)` and add to dict. Parse `year` with try/except for non-numeric values (Pitfall 4).

    **`run_letterboxd_import(user_id: str, file_bytes: bytes, db: Session, tmdb_client: httpx.AsyncClient) -> dict`** (main entry point):
    - Call `merged = _parse_csvs(file_bytes)` to get the union merge dict
    - Initialize counters: `imported = 0`, `skipped = 0`, `failed = 0`, `failed_titles: list[str] = []`
    - For now (Plan 01), just return the summary dict with zero counts — the TMDB resolution and DB write loop will be added in Plan 02. Add a `# TODO: TMDB resolution and DB writes (Plan 02)` comment at the loop location.
    - Return `{"imported": imported, "skipped": skipped, "failed": failed, "failed_titles": failed_titles}`
    - Log at INFO level: `logger.info("Parsed %d unique films from Letterboxd export", len(merged))`

    All logic in `app/import_data/workflows.py` per INFR-01.
