**Part A: Create ImportContextView.swift**

**ImportContextView struct (SwiftUI View):**
- Properties:
  - `@State private var showWebView = false`
  - `@State private var capturedZipData: Data?` (holds captured ZIP for Phase 6 handoff)

- Body layout (VStack inside ScrollView, AppTheme.background):
  1. **Letterboxd branding** at top: Use an SF Symbol for brand recognition (e.g., Image(systemName: "film.stack") or "square.and.arrow.down.on.square") -- large size (~50pt), white foreground, centered. Below it, Text "Letterboxd Import" in .system(size: 28, weight: .bold), white. Add some top padding (~60pt) to push it down from the nav bar area.

  2. **Numbered instructions card**: A VStack with dark card background (AppTheme.card), cornerRadius (AppTheme.cornerRadiusMedium), containing three numbered steps:
     - Step 1: "Log in to your Letterboxd account"
     - Step 2: "Tap \"Export Your Data\""
     - Step 3: "We'll handle the rest"
     Each step is an HStack with: a circle containing the step number (white text on AppTheme.cardSecondary background, size 28x28), then the step text (.system(size: 16), white). Steps separated by 16pt spacing. Card has 20pt internal padding and 24pt horizontal margin.

  3. **Spacer** pushing the button to the bottom

  4. **Continue button** at bottom: `AppButton(label: "Continue") { showWebView = true }` with 24pt horizontal padding and 16pt bottom padding (above safe area).

- Modifiers on the root:
  - `.background(AppTheme.background)`
  - `.navigationBarBackButtonHidden(false)` (keep the default back button for returning to Profile)
  - `.fullScreenCover(isPresented: $showWebView)` presenting `LetterboxdWebView(onZipCaptured: { data in capturedZipData = data; showWebView = false })`. When ZIP is captured, dismiss the webview. Phase 6 will add upload logic here -- for now just store the data and dismiss.

Follow project conventions. No SwipeBackGestureModifier needed since we are NOT hiding the back button.

private var settingsRow: some View {
    HStack {
        Button {
            showImportContext = true

}
