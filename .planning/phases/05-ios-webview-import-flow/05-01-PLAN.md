  <name>Task 1: Create reusable WebView UIViewRepresentable with download interception</name>
  <files>blnd_ios/blnd_ios/Views/Shared/WebView.swift</files>
  <action>
Create `blnd_ios/blnd_ios/Views/Shared/WebView.swift` containing a `WebView` struct conforming to `UIViewRepresentable` and an inner `Coordinator` class conforming to both `WKNavigationDelegate` and `WKDownloadDelegate`.

**WebView struct:**
- Properties: `let url: URL`, `let onDownloadComplete: (Data) -> Void`, `let onDownloadFailed: (Error) -> Void`, `@Binding var isLoading: Bool`
- `makeCoordinator()`: create Coordinator passing all callbacks and isLoading binding
- `makeUIView(context:)`: create `WKWebViewConfiguration` with `.default()` websiteDataStore (not `.nonPersistent()` -- cookies must persist for Letterboxd login). Create `WKWebView` with that config. Set `navigationDelegate = context.coordinator`. Set `allowsBackForwardNavigationGestures = false`. Set `isOpaque = false`, `backgroundColor = .black`, `scrollView.backgroundColor = .black`. Load the URL. Store a strong reference to the WKWebView on the Coordinator (`context.coordinator.webView = webView`) so the Coordinator is not deallocated. Return the webView.
- `updateUIView(_:context:)`: empty (no-op)

**Coordinator class (NSObject, WKNavigationDelegate, WKDownloadDelegate):**
- Stored properties: `onDownloadComplete: (Data) -> Void`, `onDownloadFailed: (Error) -> Void`, `isLoading: Binding<Bool>`, `fileDestinationURL: URL?`, `currentDownload: WKDownload?` (strong reference to prevent deallocation), `weak var webView: WKWebView?`
- Init takes all callback params and isLoading binding

- WKNavigationDelegate methods:
  1. `webView(_:didStartProvisionalNavigation:)` -- set `isLoading.wrappedValue = true`
  2. `webView(_:didFinish:)` -- set `isLoading.wrappedValue = false`
  3. `webView(_:didFail:withError:)` -- set `isLoading.wrappedValue = false`
  4. `webView(_:decidePolicyFor navigationResponse:decisionHandler:)` -- check MIME type against downloadable set: "application/zip", "application/octet-stream", "application/x-zip-compressed", "application/x-zip". Also check if URL path extension is "zip". Also check Content-Disposition header for "attachment". If any match, call `decisionHandler(.download)`. Otherwise `decisionHandler(.allow)`.
  5. `webView(_:decidePolicyFor navigationAction:decisionHandler:)` -- check if the URL contains "export" in path AND has ".zip" extension. If so, `decisionHandler(.download)`. Otherwise `decisionHandler(.allow)`.
  6. `webView(_:navigationResponse:didBecome download:)` -- set `download.delegate = self`, store `currentDownload = download`
  7. `webView(_:navigationAction:didBecome download:)` -- set `download.delegate = self`, store `currentDownload = download`

- WKDownloadDelegate methods:
  1. `download(_:decideDestinationUsing:suggestedFilename:completionHandler:)` -- create temp file URL in `FileManager.default.temporaryDirectory` appending suggestedFilename. Remove existing file at that path with `try? FileManager.default.removeItem(at:)`. Store as `fileDestinationURL`. Call `completionHandler(fileURL)`.
  2. `downloadDidFinish(_:)` -- guard `fileDestinationURL`. Read file into `Data(contentsOf:)`. Defer `try? FileManager.default.removeItem(at:)` for cleanup. Call `onDownloadComplete(data)` on main thread via `DispatchQueue.main.async`. Clear `currentDownload = nil`.
  3. `download(_:didFailWithError:resumeData:)` -- call `onDownloadFailed(error)` on main thread. Clear `currentDownload = nil`.

- Private helper: `isDownloadableResponse(_ response: WKNavigationResponse) -> Bool` that checks MIME type set, URL extension, and Content-Disposition.

Import `WebKit` and `SwiftUI`. Follow project conventions: `///` doc comments for the public struct and Coordinator, `//` for inline comments. Keep lines under 120 chars.
