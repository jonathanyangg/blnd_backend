<objective>
Wire a taste-profile rebuild into the Letterboxd import endpoint so that every successful import automatically updates the user's recommendations — without blocking the import response.

Purpose: After a bulk import, the user's taste profile is stale (hundreds of new ratings were just written). Without a rebuild trigger, the user sees outdated recommendations until they manually refresh. This phase closes that gap by adding a non-blocking background task that fires only when new data was actually imported.

Output: Modified `import_data/views.py` with a BackgroundTasks rebuild hook, plus a pytest test suite that verifies the conditional dispatch behavior.
</objective>
